# 📧 Email Spam Detection System

An interactive machine learning-powered web application designed to detect and classify emails as **Spam** or **Ham** (Legitimate).

---

## 🚀 Features
- Real-time spam content analysis.
- Clean and responsive user interface.
- Keyword and pattern-based classification algorithms.

---

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Core Logic:** Machine Learning (Naïve Bayes / NLP classification principles)
